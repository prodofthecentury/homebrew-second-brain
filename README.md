# Homebrew Tap for Second Brain

Official Homebrew tap for [Second Brain](https://github.com/prodofthecentury/second-brain) (`v1.0.0`).

## Install Desktop App (macOS Universal Cask)

```bash
brew tap prodofthecentury/second-brain
brew install --cask second-brain
```

## Install CLI Formula

```bash
brew tap prodofthecentury/second-brain
brew install second-brain
```
